# Transfer Optimiser test matrix

The dedicated Stage 6 suite covers:

- versioned transfer rules
- selling-price rounding
- free-transfer and hit formulas
- exact squad size, distinctness and position quotas
- deterministic legal best-XI selection
- mandatory zero-transfer baseline
- pooled multi-transfer affordability
- unavailable and doubtful incoming-player policy
- production/reference-search equivalence on a reduced pool
- fail-closed evaluation ceiling

The repository-wide suite remains the final regression boundary. Additional cases found during review must be added without weakening existing tests.
